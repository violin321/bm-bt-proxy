## Direction contract

THESIS: 先理解整体搜索运行，再定位某个源与某次请求。

OWN-WORLD: 白色横向导航、冷浅灰工作面、蓝色操作，细分隔线组织数字与趋势。Avenir Next / 中文系统字体，等宽字体只用于配置与原始数据。保留原生表单、原生 dialog 和一致图标。

FIRST VIEWPORT: 横向四页导航；运行概览标题、日期范围与搜索动作；四项运行指标；趋势与请求结果构成并排。往下是实际配置的源、最近请求。两个源也形成完整的业务首页，十个源使用同一网格扩展。

STORY: 今天／七天 → 请求数／耗时 → 源响应 → 请求明细 → 重新搜索或编辑源配置。

SIGNATURE: 细小的源请求历史段从实际完成记录产生；未知留空，配置修改后旧状态失效。统计中全部成功／部分成功／全部失败分别计算。

QUALITY BAR: 与选定原型保持布局、蓝白配色和信息顺序；所有原功能与防呆保留；无虚构统计；服务端记录在重启后保留；桌面和手机完成相同操作。

BUILD PATH: code-led，延续已选可交互原型。不生成新的图片方向，不把此前未完成的 comps 流程当成本轮验收证据。

FINISH: 原功能回归、统计数据契约、桌面与手机截图、独立 finish review、最终系统文档。只在本地实现与预览，不推送或部署。
