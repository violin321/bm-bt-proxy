# DB Online 未找到影片误报 502 修复

2026-11-08（Asia/Shanghai），OVH 适配器 `0.3.1` 已上线。BM-BT 保持 `1.9.0`，DB Online 保持 `1.16.102`。

## 原因

BM-BT 最近的 JavDB 源出现部分查询 HTTP 502。重放最近失败请求，旧适配器连续两次在不到一秒内返回 502；绕过适配器读取 DB Online 详情接口，实际为 HTTP 200、`success=false`，错误文案为“无法获取影片信息: 未找到匹配的影片: 番号”。旧适配器仅识别“未找到影片:”等旧文案，因而把正常无匹配误报成上游故障。

最近 200 个包含该源的请求有 11 次失败。抽查其中四个不同查询，均属于上述文案；这不是对全部历史失败的逐条归因。已知有资源的对照查询仍返回 17 条。

## 修复与验证

- 只在详情请求、`success` 为布尔 `false`、错误为字符串、完整文案与本次详情番号一致时，接收新文案为成功空列表。原文案兼容保持；认证、限流、HTTP 故障、非 JSON、结构异常和其他上游失败继续报错。
- 新增真实调用路径的端点回归，修复前复现 `502 != 200`；修复后本地和 OVH 实际镜像各通过 37 项适配器测试。
- OVH 隔离候选重放四个历史失败查询，旧版均为 502、新版均为 200 空列表；正常 17 条资源响应和旧文案空结果与旧适配器完整相等。
- 生产 BM-BT 单源六组检查通过：四个历史失败、一个正常资源对照、一个旧文案不存在对照。全源查询四个启用源全部成功，聚合去重后 26 条。
