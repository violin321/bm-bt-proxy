## 当前运行版本

顶部与页脚显示当前连接服务的版本；点击顶部版本可进入“设置 → 版本信息”，查看完整版本、构建提交短编号和发布记录。版本来自受登录保护的 `/api/version`，与 OpenAPI 共用应用版本常量。读取失败显示明确状态并可重试，不把远端发布版本当作已安装版本。镜像构建传入实际提交 SHA；本地运行未提供时明确显示“未提供构建编号”。

## 资源标签

“设置 → BM-BT 聚合规则 → 资源标签与返回顺序”列出四类支持的资源属性：

| 标签 | 上游字段 | 含义 |
| --- | --- | --- |
| 免流 | `free` | 上游明确标注免流；公共站点不因此自动标注 |
| 中文字幕 | `chinese` / `c_sub` | 上游标注有中文字幕 |
| UC / 无码 | `uc` / `uncensored` | 上游标注无码或破解 |
| UHD / 4K | `uhd` / `hd` | 上游高清标记，实际分辨率以资源信息为准 |

搜索结果新增各标签的条数，卡片补齐免流标签。计数使用与现有排序一致的显式布尔标记，不把字符串 `"false"` 当成真；未标记不代表资源一定不具备该属性。同一结果可计入多个标签。源编辑中的“分类标签”仍为自定义源管理标签，与这些资源属性分开。

资源偏好默认关闭，优先/靠后及顺序沿用 1.5.0 行为。BM-BT 设置不会改写 Byte-Muse 自身过滤与排序规则。

## Byte-Muse 接入配置

导航改为“设置”，分开呈现“连接 Byte-Muse”“BM-BT 聚合规则”“版本信息”。接入区提供当前访问地址、Docker 同网络和自定义服务地址三种选择；生成可合并到 Byte-Muse 服务 `environment` 的映射格式：

```yaml
BT_URL: "http://bm-bt-proxy:8000/api/torrents"
BT_METHOD: "get"
BT_HEADER: "{}"
BT_JSON_DATA: ""
```

开启接口保护时，复制内容中的 `BT_HEADER` 包含已保存的 `X-API-Key`。屏幕预览隐藏密钥；JSON、YAML 引号和 Docker Compose 的 `$` 插值均作转义。输入无效服务地址时禁用复制，保留已有接口的令牌参数地址复制能力。手动填写入口提供单独复制真实 `BT_HEADER`。不自动修改 Byte-Muse 容器、Compose 或持久设置。

Docker 服务名只有在同一网络内可用；远程容器的 `localhost` 指向它自身。已有持久 BT 配置时，需在 Byte-Muse 管理页核对实际生效值。保存 BM-BT 接口保护后，接入配置使用新保存的密钥更新，未保存草稿不改变复制内容。
