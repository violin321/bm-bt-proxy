## 展示与兼容

- “搜索与测试 → 上游返回的标签”按源显示去重前的标签和各自记录数，即使某源的结果全部被去重也可查看。显示的仅是本次查询，不能代表该源全部可用标签。
- 同一区域可展开查看原始布尔字段的 true / false 数量；缺失值和字符串 `"false"` 不计作布尔值。失败、空结果与未提供文字标签分别说明。
- 卡片显示最终保留记录的原始标签；聚合后的四项排序属性单独折叠展示。设置区改称“排序属性与返回顺序”，说明实际标签的查看位置。
- Jackett 仅保留 CategoryDesc、Label、Genres 的文字值，分别映射为 category、tags、genres。不会复制详情链接、下载地址或原始错误作为标签。
- DB Online 的 `tags` 仅保留字符串／对象的 name；不复制标签对象中的其他字段。原始布尔属性保存在 `upstream_flags` 中，和推断出的排序属性分开，避免新透传的 hd 意外参与既有 UHD 别名排序。
- 标签值每项最多80字，每个字段最多32项；本次源汇总最多展示120种标签并提示截断。只读取 tags、labels、category、categories、genres，过滤 URL 与凭据赋值式字符串，页面使用文字节点。
- 原有搜索接口仍返回 `{data: [...]}`。管理测试接口新增 `details[].resource_metadata`；不写入请求历史，不合并重复记录的冲突标签，不改变源优先级。生产排序偏好保持关闭。
