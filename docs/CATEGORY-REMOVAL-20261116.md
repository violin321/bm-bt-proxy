# 移除源分类候选

排序候选不再收集或展示 `category`、`categories`、`category_ids`，移除 AVDB / 修仙的文章分类目录和 Jackett 声明分类目录。保留资源自身的 `tags` / `labels`、影片风格 `genres`，以及免流、字幕、无码、UHD 等排序属性。

标签缓存每次维护时清理旧分类记录、分类目录快照及相关同步状态；后续搜索不重新积累分类，后台和手动目录同步仅请求 DB Online 缓存影片风格。旧分类快照导入被拒绝。页面的类型筛选、候选列表、自动补全和高级字段选择均不再提供源分类。

搜索结果的原始分类字段仍透传，既有分类排序规则继续匹配原字段。清理只涉及排序候选缓存，不删除资源、源站分类、请求历史、源配置或已有排序规则。

原文章分类读取函数仍保留用于已有目录登录协议的权限校验，但不参与候选目录同步。管理界面的目录登录配置保持兼容；它不会重新生成已移除的分类候选。

2026-11-16 已在 OVH 部署 1.10.1 本地构建并执行缓存清理；以下保留该次本地构建的验收记录。正式发布与固定摘要镜像验收以 v1.10.1 Release 及其附带证据为准。
