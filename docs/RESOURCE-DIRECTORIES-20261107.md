# 上游资源分类目录

BM-BT 1.7.0，2026-11-07。

## 使用方式

“设置 → 资源标签目录”优先列出源提供的分类，再补充成功搜索中发现的标签。点击项目加入限定来源、字段的排序草稿；保存返回顺序后生效，原有排序开关和规则顺序不变。

- “刷新列表”只读 BM-BT 缓存。
- “同步源目录”串行读取当前筛选源或全部启用源的目录接口，不运行搜索或遍历资源。请求立即返回，页面显示同步进度。
- 每项区分目录、搜索发现或两者都有。目录中的资源数量与搜索累计命中次数分别展示，不能混为全库资源数。
- 每源目录最多 1000 项，搜索发现最多 200 项；可分批展开或在完整缓存中搜索。达到上限明确提示，不宣称完整。

## 目录范围与权限

AVDB / 修仙兼容源通过已配置磁链接口同路径下的 `/api/v1/articles/categories` 自动识别读取。AVDB 已核实该接口统计当前文章数据库的 category，搜索磁链也返回该字段；它是当前库已有分类的目录，不包含所有未来可能出现的值。修仙需以其实际响应为准。

磁链 API Key 可能无分类读取权限。数据源编辑中的“目录认证请求头”可单独配置登录认证；默认继承搜索请求头，专用值覆盖同名字段，仅用于目录请求。已保存值不回显，留空保留，勾选明确清除后才删除。不要为了读取目录降低源服务的认证要求。也可对每源关闭目录同步。

Jackett 仅读当前所选站点的 `t=caps`，保持 Knaben 选择。目录含标准和站点自定义分类，不保证各类当前都有资源，也不等于 Label / Genres 自由标签全集。资源保留原始 Category IDs；目录选项以友好名和 ID 显示，规则保存 `field: category_ids`、数字字符串 value，按 ID 完全匹配，避免逗号组合的 CategoryDesc 和自定义名称映射造成误匹配。

DB Online 的影片风格不作为完整资源标签目录；未识别目录协议的源继续累计搜索标签。

## 缓存和兼容

目录与观察标签分别持久化在 `/data/resource-labels.sqlite3` 的独立表中。成功目录有效期 24 小时，后台每小时检查，失败一小时后重试；同时只运行一个串行同步任务。失败保留上次成功目录并显示权限、失败及待更新状态。禁用源不自动请求。

源 URL、认证、协议等请求配置仍使用原有指纹和修订号，避免变更后旧结果污染。目录模式和专用认证使用独立指纹/修订号，不改变原有搜索指纹、请求历史和观察标签；目录配置变更清除对应旧目录。晚到的响应和持有旧配置的读取不能覆盖或删除新配置目录。

目录接口为认证管理接口：GET `/api/resource-labels`，POST `/api/resource-labels/refresh`。公开搜索仍只返回 `data`；原有请求头、API Key、错误处理、超时、去重、无标签记录及稳定排序保留。原有规则为空时仍保持关闭，不因读取目录自动启用排序。

## 受信任的只读快照

当分类接口缺少登录权限，但管理员有权只读检查本地源数据库时，可导入分类快照。工具不接触原始资源或凭据，不修改源数据库，也不需要共享数据库卷到 BM-BT。

快照格式：

```json
{"coverage":"current_database","labels":[{"field":"category","value":"无码破解","catalog_count":18409}]}
```

用 `python -m app.catalog_import /path/to/snapshot.json --source-id SOURCE_ID --expected-key CURRENT_CATALOG_FINGERPRINT` 导入实例缓存。指纹必须来自当前配置，变更后拒绝导入；文件最多 2 MiB，标签按正常规则校验，界面明确显示目录快照和更新时间。快照不是自动更新的目录；后续同步失败会保留快照并提示原因。
