## 目录登录

此前只能粘贴目录 Cookie / Authorization。现在 AVDB / 修仙兼容路径 `/api/v1/articles/torrents` 可选择账号密码，保存源时由服务端请求同源的 `/api/v1/users/login`，验证目录读取成功后才保存 Bearer 会话。支持当前 AVDB 返回的二次验证挑战和一次性验证码；同时兼容修仙直接返回 `access_token` 的形式。

账号、密码、验证码不进入持久配置或管理响应，也不写请求历史。会话存入原目录专用请求头，仍只显示是否已保存。认证失败、超时、无效格式、跳转或无目录权限均不保存本次源修改；留空编辑保留原认证，明确勾选清除才删除。密码不保留，因此会话过期需要手动重新登录，不提供自动续期承诺。其他源沿用高级请求头，Jackett 沿用其 API Key。

上游登录接口以当前 OVH 两个源的 OpenAPI 和 AVDB 运行源码核实；真实账号密码登录尚需用户在页面填写源站凭据。验证使用隔离合成账号，未重置源站密码、获取账号密码散列或修改源站认证。

目录解析兼容 AVDB 扁平版块结构与修仙嵌套 `sections`；只提取原有 `category` 字段，不把版块名称伪装成资源标签。
