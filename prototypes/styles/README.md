# BM-BT 前端风格预览

这是一组等待用户选择的设计原型，与 app/static 正式实现隔离。
使用 frontend-design 的整体设计方式，比较三种结构、密度和交互路径。

1. 素白工作台：顶部导航、完整源表、行内问题详情。密度高，适合频繁管理。
2. 深色诊断台：窄导航、源列表、固定请求详情。排查时上下文完整，需要较宽屏幕。
3. 暖灰资料库：侧栏分类、源卡片、就近操作。轻松易读，同屏源数量较少。

三个方案使用相同的合成数据，状态来自样例，并非真实检测。
可以筛选、切换工作区、开关源、模拟测试、查看问题和编辑源配置。
原型不会访问原后端或真实上游，修改仅存在当前页面的内存中。
键盘 1 / 2 / 3 或左右箭头切换风格；输入时不拦截这些按键。

当前已实现的前端保留在 codex/frontend-redesign 分支，用户已要求暂停整合。
选定方案后再应用至实际页面，原功能和防呆仍需以完整回归检查为准。
当前版本最后一次浏览器回归为 26 项通过，独立审阅修复已落地，复核与最终设计文档尚待继续。

本地启动：

    python3 -m http.server 8767 --bind 127.0.0.1 --directory prototypes/styles

访问 http://127.0.0.1:8767/ 。v=1 / v=2 / v=3 可直接进入指定方案。
