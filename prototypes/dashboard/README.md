# BM-BT 运行概览方案

2026-11-06，新一轮设计方向预览，尚未选择或整合。

- 素白运行台：横向导航，请求趋势优先，源状态与最近请求随其后。
- 深色诊断台：异常提示优先，请求记录与源状态并排。
- 混合工作台：石墨导航、纸白工作区，先看两个源，再看聚合统计。

使用用户提供的修仙与 AVDB 名称、地址。所有请求量、耗时、状态、结果数、历史条均为合成示例。请求方式、参数、超时也是示例配置，未核对生产配置。
页面不会请求原后端或实际源站，不向生产写入。当前后端没有历史统计存储，统计和日志需要另行实现。
可以切换日期范围、图表指标、异常筛选，查看请求详情，编辑源、测试，以及在 2 / 10 个源之间预览密度。
正式整合仍暂停，选定方向后保留原有 API 兼容性与防呆，执行完整回归。

本地启动：python3 -m http.server 8768 --bind 127.0.0.1 --directory prototypes/dashboard

地址：http://127.0.0.1:8768/?v=1（v 为 1、2、3）。
